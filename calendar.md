**★ 🖥️ Wednesday 08.04. 19:00/19:30 Linux Tinker+Install Party 🐧**\
Join us for a Linux Tinker+Install Party at Heart of Code 🌈 No matter
if you know nothing about Linux or are a veteran: Everyone is welcome!
We will start at 19:00 with a quick Intro to Linux covering the What?,
Why?, How? and what you need to know to get started and install Linux
for the very first time. If you want to join us for that make sure to be
punctual! For everyone else the space is open from 19:30 to tinker with
your setup, install Linux (again), help the others with their setup,
discuss where Linux is heading or anything else Linux related really.
Let's abolish big tech operating systems (OS) (Windows, MacOS) and
embrace free and open source software (FOSS)!

Some more infos for everyone new to Linux:\
If you want to use the opportunity beyond the intro to actually install
and play around with Linux for the first time make sure to bring some
form of storage and a computer. All computers currently running Windows
should work perfectly fine. Any Macs with an M3 chip or later won't
work. If you don't have access to a laptop let us know
([https://heartofcode.org/contact](https://heartofcode.org/contact))
and we can organize a setup for you to play around with at the event. UK
There are multiple options for an installation:

- A simple thumb or external drive (preferablly 32GB in size) which you
  can use to temporarily launch Linux from with your laptop. This is a
  great option for anyone unsure wanting to play around and test first.
- A computer with with free space on its internal drive. The drive can
  be partitioned (split into parts) and Linux can be installed on a
  partition and launched alongside your current OS leaving it completely
  intact. This is called dualbooting.
- A computer with an internal drive which can be wiped clean and become
  your new Linux machine. This requires a backup if there is anything
  import still on that drive. Maybe you have some old laptop(s) laying
  sitting around somewhere without using them? This is a great way to
  give them a second life! Linux doesn't need much power to run.
- Pick one and come prepared!

(Please note that you need a thumb drive for any of the installation
options for booting and starting the installation process!)

There will be people speaking german and english at the event. The
slides of the Intro to Linux will be in english. The Intro will be held
in english or german depending on the audience.\
Love, Murphy & lislis

Slides:
[https://me.murphy.science/stuff/IntroToLinux.pdf](https://me.murphy.science/stuff/IntroToLinux.pdf)

**english**\
We want to create zines together, i.e. small (or large) paper products
with several pages. They can be bound or stapled, glued or folded. On
